## Deploy on Vercel

This repo is a standard Next.js 14 app.

1. Import the GitHub repository at [vercel.com/new](https://vercel.com/new)
2. Framework preset: **Next.js**
3. Root directory: `.`
4. Build command: `next build`
5. Deploy

Or from the CLI (once logged in):

```bash
npx vercel --yes --prod
```
